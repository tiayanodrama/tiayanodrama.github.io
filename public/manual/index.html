// ABOUT TT · 一份小小的自白

大家好，我是 TT。从财务的报表和数字出发，经过写作的练习场，再走进 AI 的实战——这条路径每一步都算数。喜欢用数据和逻辑把事情想清楚，也喜欢用文字把感受表达出来，这两件事在我这里并不矛盾。

来这个项目，是想补一段真实的 AI 实战经历，也想认认真真把 AI Agent 这套东西弄懂，把一段段经历做成拿得出手的作品集。

更远一点的小心思是——想成为一个 "超级个体"，能一个人 + 一些得力的工具，做成一些原本要靠一整个团队才能做的事。

// WHEN I RECEIVE A TASK · 一点点我的小心思
✦
开工前的五个小心愿
如果你愿意为我提前告诉我这五件事，我就会比较安心、比较快地上手——
  • 最终要交付的是什么
  • 什么时候要交
  • 完成它需要什么条件
  • 我负责哪一块
  • 有没有可以参考的案例
信息齐了，心里有数，进入状态就快了。
✦
我的小节奏
我习惯 "先粗后细"——先把东西大致做出来，再慢慢打磨。
完成比完美重要，是我的信条。
状态好、不拖沓的日子，1-3 天能出第一版。
我比较高效的小条件：
  • 对事情真的有兴趣
  • 一点点适度的紧迫感
  • 能看到做出来的回报
✦
我心里的"可以交"标准
自己来回看几遍，挑不出错；再换个角度想"别人收到会不会觉得还行"，就放心交了。
AI 是我工作中的全能小搭档——
  • 帮我判断轻重缓急
  • 搭框架、抠细节
  • 查漏补缺、补信息差
  • 优化表达、整理归档

我的沟通方式

// HOW WE TALK
// 习惯
语音或语音转文字，边说边想，慢慢把思绪理出来。紧张的时候语速会自然变快一些。
// 最舒服的方式
直接告诉我需求和 DDL，别让太多杂乱信息干扰。工作场景里的语音麻烦尽量说话清晰一点～
// 我不太擅长的
人多抢话的场合容易插不上话；别人绕弯子甚至带点刺的时候我会 后知后觉。请多包涵。
// 信息颗粒度
结论先行，背景细节跟上。低信息量的纯寒暄反而让我有点累，希望是舒缓语气里的高效。
// 05 OF 13
// FEEDBACK × STRESS
// GREEN WALL · 那个时候的我
// FEEDBACK 给别人的
习惯先说问题再补一句肯定
把难处先解决，后面的欣赏会更真诚一些。比起"欲抑先扬"的套路，我更喜欢直接、舒缓、不委屈任何一方的方式。
// FEEDBACK 希望收到的
具体一点，告诉我哪里能改
语气舒缓、就事论事、再自然一点就最好了。如果涉及到人格层面，消化的周期会长一些，请多给我一点时间。
// STRESS 压力下的我
自己察觉会慢一拍，队友可以这样观察——
回消息变慢、琢磨时间变长、开口变少、整个人开始拧巴不自信。如果真到这一步，请帮我分担一些任务，比一百句"你还好吗"都管用。

让我发挥得更好的支持

// HOW TO HELP ME DO MY BEST
✦
信息支持
永远是个目标导向的人——给我一个清晰的终点，再附上足够的背景材料和参考，我就能开始创造。最重要的是看到前方的目标。

资源支持

人际支持
希望身边有一个像"小灵通"那样的前辈：信息靠谱、方向精准、情商阅历都高我一阶但又不远到我够不着。一起聊、一起想，是最踏实的事。
✦
我能给别人的
我更愿意做"支持型"的角色——粘合团队、连接技术与业务、出谋划策但不直接承担最大拍板压力。学者型 / 创造型的帮忙手，是我最能创造价值的位置。
